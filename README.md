# **Goldberg–Tarjan Max Flow Visualizer**

An interactive React application that visualizes the **Goldberg–Tarjan (Push–Relabel)** algorithm for finding the maximum flow in a network. This tool provides a step-by-step graphical representation of how the algorithm pushes excess flow and relabels nodes to reach a solution.

## **Features**

- **Interactive Graph:** Visualizes nodes, edges, flow, capacity, and height labels.  
- **Step-by-Step Execution:** Watch the algorithm run automatically or step through it manually.  
- **Algorithm Logic Logs:** Detailed sidebar logs explaining every **Push** and **Relabel** operation.  
- **Dynamic Graphs:** Generate random flow networks to test different scenarios.

---

## **Tech Stack**

- **React (Vite)**  
- **Tailwind CSS v4** (Styling)  
- **Lucide React** (Icons)

---

## **Quick Start**

### **Install Dependencies**
```bash
npm install
```

### **Start the development server**
```bash
npm run dev
```

**Open in browser** Click the link provided in the terminal (`http://localhost:5173`) to view the visualization.
